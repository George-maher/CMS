# Contributing to Church Management System (CMS)

## ⚠️ IMPORTANT NOTICE

The Church Management System (CMS) is **proprietary commercial software**.
This project is NOT open source.

## Contribution Policy

### Internal Contributions
Contributions from authorized team members with a valid commercial
license agreement are welcome. All internal contributions must:

1. Follow the project's coding standards and architecture rules
2. Include appropriate tests
3. Pass all CI checks (PHPStan, Pint, ESLint, TypeScript)
4. Be reviewed by at least one other authorized contributor
5. Respect all intellectual property protections

### External Contributions
External contributions are **not accepted** at this time. This includes:

- Pull requests from non-licensed individuals
- Feature suggestions that modify core functionality
- Code submissions from outside the authorized development team

### Bug Reports
Security vulnerabilities: See [SECURITY.md](SECURITY.md)
Non-security bugs: Use the GitHub issue tracker if you are a licensed user.

### Feature Requests
Licensed customers may submit feature requests through the official
support channel.

## Code of Conduct

All authorized contributors must maintain confidentiality of the
proprietary codebase and respect intellectual property rights.

## Legal Agreement

By contributing to this project, you agree that:
- Your contributions become the property of the Licensor
- You assign all rights, title, and interest in your contributions
- You will not disclose any proprietary information
- You will comply with all terms in the LICENSE file
